# Fitted-versus-production replay — October 25, 2026

This is a paired comparison of fixed fitted candidates with actual archived pregame production forecasts. It does not fabricate earlier inputs for the current full model.

Inputs include 551 deduplicated earlier production player forecasts from ten games, the original hash-verified October 24 T60 freeze from the current model (56 forecasts in the four selected markets), its official-final grade, and the fitted-model report from successful run 40145181210. The 2024–2026 chronological holdout report supplied the fixed fitted models; this replay does not refit or select coefficients. Model hashes and selection cutoffs are verified. Current pitcher-K engine output is reproduced exactly from the October 24 saved game inputs. Hitter comparisons use the actual frozen point predictions. Legacy model versions remain separate cohorts.

The runner reads authenticated, verified historical training-day records, advances the shared fitted-state accumulator in chronological order, and predicts each selected game before adding that day's outcomes. Four read requests can run concurrently, but state updates and prediction precede label ingestion in chronological order. Same-day results cannot enter a feature vector. Only actual starting players with eligible historical operands are scored; missing players, insufficient history, missing targets and disagreements with previous settlements are explicit exclusions.

Earlier D1 quote/checkpoint duplicates are reduced to one forecast per game, player, market and model version: prefer T60, then T15, then earliest other capture. The original source/observation/state timestamps must precede first pitch and capture. Candidate eligibility is evaluated only after that candidate's fixed selection date. Every matched row retains production evidence ID, source hash, feature hash, model hash, snapshot time and prior-source dates. The point forecasts include original rounding. Accuracy uses original zero predictions; only a diagnostic deviance logarithm uses a numerical epsilon.

Reports provide MAE, RMSE, signed bias, common-Poisson count calibration diagnostics, regular/postseason segments and paired game-clustered error differences. No normal-approximation interval is emitted below 30 independent games. Players and checkpoints do not manufacture additional independent games. Count probabilities are a common-link diagnostic, not replayed executable venue probabilities. No historical quote, price, ROI or wager authority is inferred.

This is follow-up analysis after the original holdout report was inspected, not a newly untouched test set. Three years of game outcomes do not imply three years of archived current-production forecasts or historical Pal/weather states. The current-version paired cohort is one completed game; legacy-version evidence cannot establish that a fitted model beats today's complete production model. This run changes no live projection, promotion threshold, star rating or wager permission.
