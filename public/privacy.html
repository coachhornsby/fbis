FBIS Privacy Policy

Last updated: November 6, 2026

FBIS Drive Integration is a privately operated application used to manage authorized FBIS project data through Google Drive.

Google Drive Access

When authorized by the Google account owner, the integration requests access to specific Google Drive files using the Google Drive API. This access may include reading, creating, and updating files used for FBIS operations.

Use of Information

Google Drive data accessed through this integration is intended for FBIS storage, backups, research records, and operational data management. The integration is not intended to sell Google user data or use it for advertising.

Storage and Security

Authentication credentials are intended to be stored in protected configuration or secret-management systems rather than published in source code. Access to project data is intended to be limited to authorized operations.

Revoking Access

The Google account owner can revoke the application's access at Google Account Connections.
