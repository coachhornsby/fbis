# Fitted model deployment, 2026-10-25

The four fitted Poisson candidates now have a production inference path, separate immutable pregame records and official-final grading. These are live shadow deployments, not champion or wager-authority promotions.

Pitcher strikeouts and total bases have favorable retrospective MAE, deviance and game-clustered error intervals. Hits and home runs remain research comparisons. Historical acquisition is complete through October 24, but these fitted versions have zero prospective games at deployment. The existing promotion requirements in `mlbPropPromotionGovernance.js` remain unchanged: 45 distinct dates, 14 prospective days, directional coverage, distance-bucket behavior, calibration and material-segment checks. Historical replay cannot satisfy those live-source requirements. Exact-line economic evidence is also absent. No unconditional activation endpoint accepts client-provided readiness claims.

Live inference exactly reproduces the training operands: prior 90-day unweighted metric numerators/denominators, the last five prior-start BF average and cumulative opposing-team K rate for pitchers; cumulative prior starting-hitter outcomes and recent ten-game PA opportunity for hitters. It does not apply learned coefficients to the different production baseline or add Pal factors a second time. Pal remains in the existing production comparison. Tests compare live feature vectors and baselines directly with the historical design builders.

The refresh workflow bootstraps from authenticated archived training-day records, requires contiguous acquired competitive dates, skips only the out-of-scope December–February interval, and incrementally refreshes every morning. Failure leaves the previous immutable state intact. Player metric histories are sharded; board requests read only the needed player IDs in bounded concurrent batches rather than a full multi-season archive. Model and state hashes are verified; future, stale and post-start requests cannot emit prospective candidates. The state and forecasts live in R2; no historical D1 copies are added.

`mlbFittedShadow` accompanies slate games. It preserves the existing projection rows, prices, stars and authorization. Capture runs before source reconciliation in the existing ten-minute completion workflow. The fitted freeze has its own immutable EARLY/T60/T15 namespace, so adding a fitted version never overwrites an earlier ablation record. Grades distinguish model hashes, scope and checkpoint, retain paired champion predictions, and count distinct games and dates. Retrospectively acquired operands become prospective evidence only when actually captured before a new game's start. Readiness and observed prospective cohorts are exposed by `/api/mlb-completion` under `fittedModels`.

Remaining work for champion promotion is evidence collection and exact-line economic evaluation, followed by a model-specific reviewed activation. This deployment does not claim those gates passed. SSW and xRA remain outside this phase.
